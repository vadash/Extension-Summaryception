# Regenerated replies drop their checkpoint at generation start

> Superseded by ADR-0017 (2026-09-20) via ADR-0014, which restates this rule as part of the
> consolidated decision. Amended ADR-0012: swipe and regenerate drop the last
> reply's checkpoint at generation start, so the rerolled reply is unaudited and
> the read model falls back to the prior checkpoint.
