# Summarizer style rules use construction families, not vocabulary bans

The 2026-11 audit found zero banned-word violations under both prompt sets; drift was structural: semicolon chains, transliterated quotes replacing verbatim dialogue, somatic tallies, and one comparative construction. The default prompts gain only construction-family substitution rules (tricolons, apophasis, litotes, anaphora loops, personification, em-dash joins, melodrama formulas, clause limits), a somatic-tally drop line, a verbatim-quote language rule, and a one-framing cap with prior-relative rewording — deliberately no banned-vocabulary list without new audit evidence.

## Considered Options

- **Copy the roleplay preset's banned-word list** — zero occurrences, a token tax on every call, and the Refusal Guard already exempts quoted dialogue.
- **Add mechanical gate checks now** — deferred: re-run the scenario and extend the repair gate (semicolon, clause cap) only if violations persist.

## Consequences

Rules stay RP-agnostic. Style rules (slashes, pluses, bare underscores, all-caps headers, negations) ride prompt text alone, enforced by review, not scan.
