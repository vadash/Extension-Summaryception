# Microfiche memory always images; raw photos opt in at the mode picker

Microfiche mode keeps the Prefix Cache retention budgets and changes the render path only, so its memory region images every sealed page with no toggle: the Memory Images checkbox dies and old off-state text corners go with it. The raw region stays opt-in as Old Chat Photos beside the mode picker with the Keep Raw tail, because photographing live chat is the choice the user understands, not a second expert checkbox.

## Considered Options

- **Keep the Memory Images toggle** — rejected: a Microfiche mode that ships memory as text is Prefix Cache with extra steps; the mode choice already is the toggle.
