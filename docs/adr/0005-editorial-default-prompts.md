# Editorial hierarchy as the default summarizer prompts

The default Layer 0 and promotion prompts distilled summarizer_v1.1's editorial salience and thread-maintenance rules, bound to a `[NARRATIVE]`+`[STATE]` output contract. ADR-0015 restates the surviving decision as the narrative-only contract in force today; issue #26 removed the `[STATE]` half.
